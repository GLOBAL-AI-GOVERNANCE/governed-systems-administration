# baseline-r5.2 Candidate Status

baseline-r5.2 is the sole preimplementation candidate following rejection of baseline-r4 for semantic closure.

## Local Completion Targets

- deterministic fixture identity;
- reachable, unshadowed policy rules;
- strict cross-field schemas;
- versioned success and error outcomes;
- real evidence, privacy, and no-execution tests;
- complete coverage obligations;
- exact canonical JSON, CLI, and upstream contracts;
- hardened repository verifier;
- honest claims;
- pinned verification supply chain.

## Decision Boundary

A local passing verifier does not automatically approve this baseline. Independent semantic V&V is required. A passing independent audit makes ADR-0001 eligible for explicit human review; it does not accept the ADR.
