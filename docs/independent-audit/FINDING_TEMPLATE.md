# Audit Finding Template

Copy this template once per finding.

| Field | Value |
|---|---|
| Finding ID | `AUD-` followed by a sequence number |
| Severity | High, Medium, Low, or Informational |
| Criterion | Criterion number from the kit README |
| Artifact | Path and manifest SHA-256 |
| Location | Section, JSON pointer, or line |
| Normative basis | The text the artifact fails to meet |
| Observation | What was found |
| Reproduction | Steps or minimal synthetic input |
| Expected | Result required by the normative basis |
| Actual | Result observed |
| Suggested resolution | Optional |
